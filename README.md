# codex

这是一个用于保存代码、实验、笔记和项目资料的 GitHub 仓库。

## 仓库结构

```text
.
├── README.md
├── AGENTS.md
├── .gitignore
├── src/
├── assets/
├── docs/
│   └── SETUP.md
└── notes/
    └── README.md
```

## 使用方式

- 把项目代码放在对应文件夹中。
- 把学习笔记、需求记录、想法放在 `notes/` 中。
- 每次完成一个小改动后提交一次 commit。

## 常用 Git 命令

```bash
git status
git add .
git commit -m "Update project files"
git push
```
