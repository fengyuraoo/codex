# DesignMate v0.7.3 Minimal Home UI Cleanup

## 1. 本轮目标：让首页更简单

v0.7.3 的目标不是增加新功能，而是把 DesignMate 首页从“功能展示页 / 后台仪表盘”收束成更轻量的本地 AI 搜索工具首页。用户打开页面后，第一眼应该看到产品名、定位、搜索框，以及三个最重要的动作。

## 2. 首页减少了哪些信息

- 移除了搜索框下方横跨整页的重型“添加资料”条，改成居中的轻量按钮组。
- 首页核心卡片从多个功能入口减少到 3 个：添加资料、搜索资料、问 DesignMate。
- Link Capture 和 Image Search 不再在首页重复强调，保留在顶部导航和 Add Materials 页面中。
- Dashboard 统计、项目分布、高价值资料等信息继续保留在系统里，但不再作为首页首屏的主要视觉负担。

## 3. 保留的三个核心动作

### 添加资料 / Add Materials

导入草图、链接、笔记和项目文件。它是 DesignMate 工作流的起点。

### 搜索资料 / Search Library

查找痛点、反馈、调研和页面主题，把资料从文件变成可判断的设计证据。

### 问 DesignMate / Ask DesignMate

整理证据、洞察和作品集位置。当前仍使用 rule-based fallback，不依赖 API Key。

## 4. 当前仍未完成

- 真实文件上传：Upload Files 当前仍是 UI 入口，真实文件建议放入 `DesignMate/data/inbox` 后运行扫描。
- 真实视觉理解：Image Search 当前仍基于文件名和图片元信息，未接入视觉模型。
- 真实 AI provider：Ask DesignMate 当前仍是规则版 fallback，OpenAI / DeepSeek / Ollama 仍放在后续版本。

## 5. 验收方式

- 打开首页，确认首屏只突出搜索框和三个动作按钮。
- 切换中文，确认标签显示“本地优先 / 面向作品集 / 设计证据 / 隐私友好 / 面向设计学生 / 用于作品集构建”。
- 切换英文，确认标签恢复为 “Local-first / Portfolio-aware / Design evidence / Privacy-friendly / For design students / For portfolio building”。
- 运行 `python DesignMate/scripts/quality_gate_v073.py`。
