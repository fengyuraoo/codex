# DesignMate v0.7.6 Home De-duplication + Upload Drag-and-Drop Fix

## 1. 本轮目标

v0.7.6 聚焦两个小但关键的体验问题：减少首页重复入口，并把 Add Materials 的文件拖拽上传做成稳定、清楚、可用的交互。

## 2. 为什么删除首页重复卡片

v0.7.5 首页同时在顶部导航、Hero 按钮和底部功能卡片里重复展示 Add Materials、Search Library、Ask DesignMate。对真实用户来说，这会让页面像功能展示页，而不是一个轻量搜索工具。

v0.7.6 保留顶部导航作为完整功能切换入口，Hero 只保留最重要的搜索框和两个开始动作。

## 3. 首页现在的结构

- 顶部导航：负责切换 Search Hub、Add Materials、Ask DesignMate、Text Search、Image Search、Link Capture、Reports。
- Hero 搜索区：负责 DesignMate 定位、主搜索框和 Search 操作。
- Hero CTA：只保留 Add Materials 与 Ask DesignMate。
- 标签行：只保留 Local-first、Design evidence、Project memory。
- Library Status / 资料库状态：低调展示资料总数、上传文件、采集链接、保存笔记和 API 状态。

## 4. 顶部导航、Hero CTA、资料状态区的分工

- 顶部导航是完整功能地图。
- Hero CTA 是新用户的两个起步动作：先添加资料，或直接问 DesignMate。
- 资料状态区用于给用户快速确认本地资料库是否有内容，不再承担功能入口角色。

## 5. 拖拽上传修复了什么

- 阻止浏览器把拖入文件直接打开。
- 支持 `dragenter`、`dragover`、`dragleave`、`drop` 的完整状态处理。
- drop 时读取 `event.dataTransfer.files`。
- 拖拽悬停时显示更明确的提示。
- 文件选择器和拖拽文件进入同一个待上传列表。
- 上传按钮在没有文件或 API 未连接时禁用。

## 6. 上传区现在支持

- 拖入文件。
- 点击上传区域选择文件。
- 多文件列表。
- 移除单个待上传文件。
- 重复文件去重。
- 不支持格式提示。
- 空文件或拖入文件夹的友好提示。
- API 未启动时的清楚提示。
