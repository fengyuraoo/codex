# DesignMate v0.7 Search Hub

## v0.7 产品定位

DesignMate v0.7 的目标是 **DesignMate Search Hub: A Local AI Search Hub for Design Portfolio Materials**。

它不是通用文件搜索工具，而是面向设计学生和设计从业者的本地 AI 设计资料搜索与作品集叙事工具。它帮助用户在本地检索草图、灵感图、调研资料、反馈截图、项目文档和作品集草稿，并把这些零散资料整理成可用于作品集的设计证据和叙事结构。

## 为什么不是通用本地搜索

通用本地搜索通常关注“找到文件”。DesignMate 更关注“这条资料能不能成为作品集证据”。

DesignMate 的搜索结果以 Design Evidence Card 呈现，不只显示文件名，还尝试解释：

- 这条资料属于哪个项目。
- 它处于哪个设计阶段。
- 它更像调研、草图、反馈、参考还是最终展示。
- 它可能适合放在作品集的哪个位置。
- 它为什么值得被纳入作品集叙事。

## 目标用户

- 设计学生：管理课程项目、毕业设计、作品集申请材料。
- 作品集申请者：把分散的调研、草图、反馈和展示稿整理成清晰叙事。
- 初级设计师：复盘项目过程，整理面试或作品集案例。
- 自由设计师：在本地资料库中查找项目证据，快速生成项目说明草稿。

## 核心流程

### 1. Collect

用户把 Markdown、TXT、PDF、DOCX、PPTX、JPG、PNG 放入 `DesignMate/data/inbox` 或 `DesignMate/data/library`。

### 2. Search

用户通过 Search Hub 的大搜索框或 Text Search 页面检索项目名、关键词、用户痛点、设计阶段、文件内容和作品集页面主题。

### 3. Ask

用户在 Ask DesignMate 中提问，例如“哪些资料能证明用户痛点？”或“reader-design 适合生成哪几页作品集？”。当前版本使用规则版 fallback，不依赖 API Key。

### 4. Organize

用户可以在 Detail Inspector 中编辑项目归属、资料类型、作品集阶段、标签、评分和备注，也可以批量编辑搜索结果。

### 5. Export

用户可以生成作品集页面草稿，也可以导出 DesignMate 自身的作品集案例素材，用于后续排版和展示。

## 当前版本限制

- 真实 OpenAI / DeepSeek / Ollama API 尚未接入，当前 Ask DesignMate 使用 rule-based fallback。
- 真实视觉模型尚未接入，Image Search 当前使用图片元信息、文件名、标签和备注检索。
- Electron 桌面端尚未完成，当前使用本地 API 服务和静态 Web UI。
- PDF / DOCX / PPTX 深度解析依赖本地可选库，缺少依赖时会降级为元信息记录。
- 当前搜索不是向量搜索，仍以规则匹配、字段加权和本地全文索引为主。

## 与通用本地搜索工具的区别

| 维度 | 通用本地搜索 | DesignMate Search Hub |
| --- | --- | --- |
| 目标 | 找到文件 | 找到可用于作品集的设计证据 |
| 用户 | 广泛办公用户 | 设计学生、作品集申请者、设计师 |
| 结果 | 文件列表 | Design Evidence Cards |
| 语境 | 文件名、路径、正文 | 项目、阶段、资料类型、作品集位置 |
| AI 角色 | 通用问答或摘要 | 作品集叙事助手 |
| 隐私 | 取决于工具 | 本地优先，默认不需要 API Key |
