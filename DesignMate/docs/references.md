# References

DesignMate 可以参考以下产品原则，但不与任何第三方项目形成复制或依赖关系。

## 参考方向

- 本地优先：资料默认保存在用户本地，用户能直接查看和迁移。
- 多模态资料输入：未来支持文本、图片、PDF、演示文稿等设计资料。
- 语义搜索：未来从关键词搜索升级到更符合设计语境的语义检索。
- 隐私保护：用户作品集资料、调研记录和申请材料应默认私密。
- AI 辅助整理：AI 用于分类、摘要、提问和草稿生成，不替代用户判断。
- 夜班自动推进：未来支持定时整理新增资料并生成第二天任务。

## 独立性声明

DesignMate 是从零设计与实现的独立产品，不复制第三方项目代码、界面、文档或品牌。
