# DesignMate v0.7.1 Link Capture

## 功能定位

Link Capture 是 DesignMate v0.7.1 新增的链接资料提取功能。它的目标不是做万能下载器，而是把外部网页、作品集案例、灵感图文、社交帖和短视频链接保存为可搜索、可编辑、可进入作品集叙事的设计资料。

## 为什么设计学生需要链接资料提取

设计学生和初级设计师的灵感资料并不只在本地文件夹里。很多调研线索、灵感参考、空间案例、交互案例和老师分享内容来自：

- 小红书和 Pinterest 的灵感图文。
- 抖音、B站、TikTok、YouTube 的短视频参考。
- Behance、Dribbble 和作品集网站。
- 公众号文章和普通网页文章。

如果这些链接只留在收藏夹或聊天记录里，它们很难进入作品集证据链。Link Capture 把它们转成 DesignMate 的 MaterialRecord，让它们可以被 Search、Ask DesignMate、Reports 和 Portfolio Export 使用。

## 支持的链接类型

当前平台识别包括：

- xiaohongshu / 小红书
- douyin / 抖音
- bilibili / B站
- tiktok
- youtube
- pinterest
- behance
- dribbble
- wechat article / 公众号
- generic webpage

普通公开网页会尝试提取 title、description、Open Graph cover image 和正文片段。短视频和社交平台可能限制自动访问，因此当前版本优先保存原始链接、平台、source_type 和用户手动 note。

## 短视频平台的当前限制

DesignMate v0.7.1 不会：

- 下载视频。
- 绕过登录。
- 绕过反爬限制。
- 破解平台访问控制。
- 下载受版权保护的视频内容。

如果短视频平台无法自动提取正文，DesignMate 会保存链接并提示用户补充 user note。这个 note 会进入搜索和 Ask DesignMate 的上下文。

## 数据如何进入作品集叙事

Link Capture 保存后会成为一条 link material：

- Search 中以 Design Evidence Card 展示。
- Ask DesignMate 可以把它作为 external reference、moodboard source 或 process evidence 使用。
- Portfolio Export 会把链接资料整理到 `portfolio_export/external_references.md`。
- 用户可以在前端编辑 project、design_stage、portfolio_placement 和 user_note。

## v0.8 后续方向

- 对短视频做用户授权范围内的字幕或摘要提取。
- 接入语音转写或公开视频字幕解析。
- 对网页正文做更稳定的可读性提取。
- 把外部参考与本地草图、调研、反馈建立更强关联。
