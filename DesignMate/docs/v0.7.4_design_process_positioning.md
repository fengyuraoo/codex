# DesignMate v0.7.4 Design Process Positioning

## 1. 为什么从作品集工具扩展为设计全过程工具

DesignMate 早期围绕设计学生的作品集资料整理展开，这个方向仍然重要，但它容易让产品被理解成“只在最后做作品集时才使用”。真实设计工作中，资料整理发生在更早、更长的过程中：调研、灵感收集、草图迭代、反馈记录、竞品分析、方案汇报和项目复盘都需要可追溯的证据。

因此 v0.7.4 将 DesignMate 的主定位从“作品集资料搜索助手”扩展为“设计全过程资料搜索与设计证据管理工具”。作品集仍是关键输出，但不是唯一目标。

## 2. 新产品定位

English:

DesignMate is a local AI material search and design evidence tool for the whole design process.

中文：

DesignMate 是一个面向设计全过程的本地 AI 资料搜索与设计证据管理工具。

## 3. 目标用户变化

- 设计学生
- 作品集申请者
- 工业设计师
- 产品设计师
- UX / UI 设计师
- 自由设计师
- 设计团队成员

## 4. 核心场景变化

- 设计调研资料整理
- 灵感和参考图管理
- 草图与方案迭代记录
- 用户反馈与客户反馈整理
- 竞品分析与案例收集
- 设计决策证据沉淀
- 项目复盘
- 方案汇报
- 作品集输出

## 5. 作品集在新定位中的角色

作品集从“唯一主场景”变成“重要输出场景”。DesignMate 帮助用户在项目过程中持续沉淀资料、证据和判断，当需要做作品集时，这些资料已经具备清晰来源、使用场景和设计逻辑。

## 6. 保留的功能

- Search Hub / 搜索中心
- Add Materials / 添加资料
- Text Search / 文本搜索
- Image Search / 图片搜索展示壳
- Link Capture / 链接采集
- Paste Note / 粘贴笔记
- Ask DesignMate / 问 DesignMate
- Reports / 报告
- Portfolio draft / 作品集草稿输出
- Portfolio export / 作品集案例导出
- 中英双语切换
- 本地 SQLite 与规则版 AI fallback

## 7. 当前仍未完成的能力

- 真实浏览器文件上传
- 真实视觉理解
- 真实 AI provider
- Electron 桌面打包

## 8. v0.7.4 验收重点

- 首页主标题强调 design process / 设计全过程。
- 顶部副标题不再只写 portfolio / 作品集。
- Design Evidence Card 的显示字段从 Portfolio Placement 扩展为 Use Case / 使用场景。
- Ask DesignMate 的结构从“作品集位置”扩展为“可用场景”。
- Link Capture 从“保存作品集灵感链接”扩展为“保存设计过程参考证据”。
