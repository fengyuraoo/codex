# DesignMate v0.7.2 Bilingual Design Workflow

## 1. 功能定位

DesignMate v0.7.2 增加中英双语工作流。它让 DesignMate 在中文真实整理场景和英文作品集展示场景之间切换：用户可以用中文管理资料、写备注、向 Ask DesignMate 提问，也可以切换到英文界面，用于录屏、截图、申请作品集展示和国际化叙事。

## 2. 为什么 DesignMate 需要中英双语

设计学生的资料整理常常发生在中文语境中：老师反馈、调研笔记、草图说明、课堂记录和个人备注往往是中文。但作品集申请、英文汇报、海外院校面试或国际项目展示又需要英文表达。

因此 DesignMate 不只是翻译 UI，而是支持两种工作状态：

- 中文：更适合日常整理、理解资料、补充个人备注和快速判断。
- English：更适合截图展示、作品集说明、产品 Demo 和英文申请语境。

## 3. 中英双语对作品集申请场景的价值

- 降低整理成本：中文界面更贴近设计学生真实工作流。
- 提升展示质量：英文界面适合放进作品集页面和录屏 Demo。
- 保留语境：Ask DesignMate 会根据问题语言优先返回中文或英文结构。
- 减少误解：Link Capture、Design Evidence Card、Portfolio Placement 等核心概念在两种语言中保持一致。

## 4. 中文用户流程

1. 打开 Search Hub，切换到“中”。
2. 把资料放入 `DesignMate/data/inbox` 并运行扫描。
3. 用“文本搜索”查找用户痛点、草图、老师反馈或灵感链接。
4. 在“链接采集”中粘贴小红书、B站、Behance、网页文章等参考链接。
5. 给资料补充“我的备注”和“作品集位置”。
6. 在“问 DesignMate”中提问：哪些资料能证明用户痛点？哪些链接适合放 Moodboard？
7. 查看报告和作品集草稿。

## 5. 英文展示流程

1. Switch to `EN`.
2. Open the Search Hub home screen for a clean product screenshot.
3. Use Text Search to show Design Evidence Cards.
4. Open Link Capture to demonstrate external reference capture.
5. Ask DesignMate a portfolio-oriented question.
6. Capture screenshots for Search Hub, Evidence Card, Link Capture, Ask DesignMate and Reports.

## 6. 当前限制

- 双语切换覆盖主要界面和动态卡片，但旧报告内容仍取决于生成脚本的原始语言。
- Ask DesignMate 当前仍是 rule-based fallback，不调用真实 AI API。
- Image Search 当前仍是展示壳和元信息匹配，真实视觉理解计划放到 v0.8。
- Link Capture 不下载视频、不绕过登录、不绕过平台限制。

## 7. 后续计划

- 让报告生成也支持中英输出。
- 为 Portfolio Export 增加中英文导出版式。
- 为 Link Capture 增加双语字段建议和手动标题编辑。
- 接入真实 AI provider 后，保留当前语言判断和 fallback 机制。

## 8. Add Materials / 添加资料

v0.7.2 同步补上了统一资料输入入口。它不是单独的上传弹窗，而是 DesignMate 工作流的第一步：先把资料加入本地资料库，再进入 Search、Ask、Reports 和 Export。

Add Materials 页面支持中英双语，并包含四种输入方式：

- Upload Files / 上传文件：展示拖拽上传区域。当前版本保留上传入口，建议用户先把 Markdown、TXT、PDF、Word、PPT、图片和截图放入 `DesignMate/data/inbox`，再运行 `python DesignMate/scripts/run_designmate.py`。
- Capture Link / 采集链接：复用 v0.7.1 Link Capture，把小红书、抖音、B站、Behance、Pinterest、网页文章和作品集案例链接保存为可搜索的设计证据。
- Paste Note / 粘贴笔记：用户可以直接粘贴调研记录、老师反馈、设计想法或页面草稿。笔记会通过 `/api/paste-note` 保存为 material，并进入 Search 与 Ask DesignMate。
- Import Folder / 导入文件夹：说明 DesignMate 当前推荐的本地文件夹扫描流程：把资料放入用户资料文件夹，运行扫描脚本，回到 Search Hub 检索。

这个入口让中文真实整理流程和英文作品集展示流程都更清楚：中文用户可以从“添加资料”开始管理草图、反馈和笔记，英文展示时则可以把它解释为 Material Input Hub。
