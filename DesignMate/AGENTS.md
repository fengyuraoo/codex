# AGENTS.md

DesignMate 是从零设计与实现的独立应用，目标是帮助设计学生和创作者管理作品集资料、搜索灵感与调研、整理项目逻辑，并生成作品集页面草稿。

## 长期规则

- 不复制第三方项目代码、README、UI、图标、文案或品牌表达。
- 优先完成可运行 MVP，再扩展复杂功能。
- 每次修改前检查当前目录结构和 git 状态。
- 每次修改后运行测试，至少确认核心脚本可执行。
- 每次结束前更新 `reports/dev_log.md`。
- 不删除用户资料。
- 不覆盖旧报告；需要保留 `reports/YYYY-MM-DD-designmate-report.md` 这类日期报告。
- 不确定内容标注“需确认”或“待补充”。
- 先修 bug，再做新功能。
- 文件夹和文件名优先使用英文，Markdown 内容可以使用中文。
- 所有新增功能要尽量保持本地优先和隐私保护。

## v0.1 工作重点

- 保持脚本能从项目根目录运行。
- 优先使用 Python 标准库。
- 输出 Markdown 和 JSON 文件。
- 图片、PDF、DOCX、PPTX 在未解析正文时必须明确记录限制。
