# 03 Product Features

## 本地资料扫描

用户把资料放入 `data/inbox` 或 `data/library`，运行一键脚本后，系统会扫描 Markdown、TXT、PDF、图片等文件，生成本地索引和 SQLite 数据库记录。

## 设计语境分类

系统根据文件名、正文预览和关键词推断资料类型、作品集阶段、项目归属、标签和资料评分。分类不是最终判断，用户可以在 Web UI 中继续编辑和确认。

## 本地搜索

搜索支持中文关键词、项目筛选、类型筛选、阶段筛选和同义词扩展。它服务的不是通用文件查找，而是“我要找到能证明这个设计问题的资料”。

## 资料编辑与批量整理

单个资料可以编辑项目、类型、阶段、标签、评分和备注。多个资料可以批量修改项目归属、资料类型、作品集阶段和标签，用于快速整理真实项目资料。

## 报告与草稿生成

报告展示资料分布、高价值资料、项目缺口和下一步任务。规则版作品集草稿生成器可以按项目输出页面标题、页面目标、可用资料、核心论点、文案草稿、图像建议和缺失证据。
