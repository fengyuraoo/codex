# 01 Project Overview

## 项目背景

DesignMate 是一个面向设计学生和作品集创作者的本地资料管理原型。它的起点不是“再做一个文件夹”，而是解决作品集准备阶段常见的断裂：资料散落在不同位置，调研、草图、反馈和页面草稿无法被持续回收，项目叙事往往到最后才被临时拼接。

## 目标用户

- 工业设计、交互设计、空间设计学生
- 正在整理作品集的创作者
- 需要长期积累调研、灵感、反馈和页面草稿的人

## 设计目标

DesignMate v0.5 的目标是把本地文件转化为可检索、可编辑、可报告、可生成页面草稿的作品集资料库。它强调本地优先和人工确认，先把真实资料管理流程跑通，再考虑接入更复杂的 AI 能力。

## 当前原型

当前版本包含 SQLite 数据库、全文搜索、Web UI、资料详情编辑、批量编辑、每日报告和规则版作品集页面草稿生成器。它已经可以用于演示“从资料进入系统，到成为作品集页面证据”的基本链路。
