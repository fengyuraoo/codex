# 04 User Flow

## 每日使用流程

1. 用户把当天新增资料放入 `data/inbox`。
2. 用户运行 `run_designmate.bat` 或 `python scripts/run_designmate.py`。
3. 系统扫描资料、更新 SQLite、重建搜索索引、生成报告和前端数据。
4. 用户打开 Web UI，先查看 Dashboard 的导入状态和今日建议。
5. 用户进入 Search，用项目、类型、阶段和关键词检索资料。
6. 用户点击资料卡片进入 Inspector，编辑分类、标签、评分和备注。
7. 用户使用批量编辑快速确认同一批资料的项目归属或阶段。
8. 用户查看 Reports，决定下一步补充哪些资料。
9. 用户按项目生成作品集页面草稿，作为页面写作的起点。

## 关键体验原则

- 用户不需要先理解数据库和索引，只需要放资料、运行脚本、打开网页。
- 所有自动分类都可以被人工修正。
- 报告和草稿不替代设计判断，而是把资料缺口暴露出来。
