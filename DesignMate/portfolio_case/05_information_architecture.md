# 05 Information Architecture

## 数据对象

DesignMate 的核心对象是 MaterialRecord。它把一个本地文件转化为可管理资料，包括路径、正文预览、解析状态、项目归属、资料类型、作品集阶段、标签、评分、备注和人工确认状态。

## 页面结构

- Dashboard：查看资料总览、导入状态、资料分布和今日建议。
- Search：检索资料、筛选项目、批量编辑、查看结果列表。
- Detail Inspector：编辑单个资料的分类、标签、评分和备注。
- Reports：阅读资料报告、待确认问题、下一步任务和作品集草稿入口。

## 信息层级

界面优先呈现“我现在有什么资料”和“哪些资料值得处理”。项目、类型、阶段作为主要筛选维度，标签和评分作为辅助判断。报告则从统计转向行动，把资料库状态翻译成下一步设计任务。
