# 06 Interface Pages

## Dashboard

Dashboard 用于快速判断资料库是否健康。顶部展示总资料、高价值资料、待确认资料、未分类资料和解析失败数，同时展示 inbox、library、上次扫描和上次报告生成时间。

## Search

Search 是主要工作区。用户可以用关键词搜索，也可以用项目、类型、阶段筛选。结果卡片展示文件名、项目、类型、阶段、标签、评分、摘要和人工确认状态。

## Batch Edit

批量编辑工具栏只在用户选择资料后出现，避免占用默认界面空间。它支持批量修改 project、type、stage 和 tags，用于真实资料导入后的快速整理。

## Detail Inspector

详情面板承担“人工确认”的角色。用户可以看到文件路径、解析状态、字数、摘要、作品集用途和需要确认的问题，并保存分类和备注。

## Reports

Reports 页面把 Markdown 报告渲染为更清晰的产品化阅读界面，分为 Latest Report、Need Confirm、Next Actions 和 Portfolio Draft 入口。
