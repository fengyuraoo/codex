# 作品集推进时间线

> 日期和周期可根据实际课程、申请或求职时间调整。

## 阶段 1：项目边界整理

- 时间：待定
- 目标：完成两个项目的 README 和 brief。
- 输出：
  - 阅读器设计 `brief.md`
  - 图信中心设计 `brief.md`
  - 每个项目的材料缺口清单

## 阶段 2：调研材料归档

- 时间：待定
- 目标：整理用户、场景、竞品、案例和问题证据。
- 输出：
  - 阅读器设计用户研究与竞品分析
  - 图信中心空间研究、用户旅程和案例研究
  - 初步洞察列表

## 阶段 3：概念与方向梳理

- 时间：待定
- 目标：从调研结论推导设计机会点和概念方向。
- 输出：
  - 概念方向说明
  - 草图记录
  - 分区或功能构想

## 阶段 4：发展与迭代记录

- 时间：待定
- 目标：记录造型、交互、空间、系统、材料和视觉等设计迭代。
- 输出：
  - 迭代说明文档
  - 过程图索引
  - 需要重做或补拍的材料清单

## 阶段 5：作品集页面脚本

- 时间：待定
- 目标：把每个项目整理成可排版的作品集页面逻辑。
- 输出：
  - `portfolio-page-script.md`
  - 最终说明草稿
  - 展示图清单

## 每周检查清单

- 本周新增了哪些真实材料？
- 哪些结论有证据支撑？
- 哪些图片需要补拍、重命名或重新导出？
- 哪些页面仍然缺少清晰叙事？
- 下周最小可完成任务是什么？
