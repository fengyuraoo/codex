# 作品集整体计划

## 作品集目标

建立一套清晰、可持续更新的工业设计作品集管理系统，用于整理两个核心项目的研究过程、设计判断、迭代证据和最终展示稿脚本。

## 当前核心项目

1. 阅读器设计
2. 图信中心设计

## 作品集内容原则

- 展示真实设计过程，而不是只展示最终效果。
- 每个项目需要讲清楚：问题是什么、为谁设计、为什么这样设计、如何迭代、最终方案如何回应问题。
- 过程材料应保留时间、来源和用途，方便后续追溯。
- 未完成、待确认、缺少证据的内容应明确标注。

## 推荐作品集页面结构

每个项目可按以下逻辑组织：

1. 项目一句话定位
2. 背景与设计问题
3. 目标用户与使用场景
4. 调研方法与关键发现
5. 设计机会点
6. 概念方向与方案选择
7. 设计迭代过程
8. 最终方案说明
9. 使用流程或系统关系
10. 反思与下一步

## 下一步整理优先级

1. 先补全两个项目的 `brief.md`，明确项目边界。
2. 整理已有草图、调研照片、访谈记录和参考案例。
3. 在 `insights.md` / `case-study.md` 中提炼可支撑设计方向的结论。
4. 补充概念方向和迭代记录，不急于写最终成果。
5. 最后再写 `portfolio-page-script.md`，形成作品集页面叙事。
