# 素材索引

这个文件用于登记作品集素材，避免草图、照片、模型截图、版面稿分散后找不到。

## 命名建议

```text
YYYYMMDD_project_stage_content_v01.ext
```

字段说明：

- `YYYYMMDD`：素材创建或整理日期。
- `project`：`reader` 或 `info-center`。
- `stage`：`brief`、`research`、`concept`、`development`、`final`。
- `content`：简短英文描述。
- `v01`：版本号。

## 状态标记

- `raw`：原始材料，尚未筛选。
- `selected`：已选中，可用于继续整理。
- `edited`：已处理或已重命名。
- `ready`：可用于作品集排版。
- `replace`：需要重拍、重做或替换。
