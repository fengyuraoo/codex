# portfolio/AGENTS.md

`portfolio/` 是作品集主工作区，用于管理工业设计作品集项目、资料、叙事和阶段计划。

## 项目范围

- `reader-design` 只放阅读器设计相关内容。
- `info-center-design` 只放图信中心设计相关内容。
- 优先修改现有文件和目录，不要重复创建相似项目目录。
- 文件夹和文件名优先使用英文，Markdown 内容可以使用中文。

## 项目组织

每个项目都应围绕以下内容组织：

- `brief`
- `research`
- `concept`
- `development`
- `final`
- `notes`
- `assets`

项目文档应服务于作品集表达，不是普通论文。

## 作品集叙事

作品集叙事优先采用：

问题发现 → 调研 → 洞察 → 概念 → 迭代 → 最终方案 → 反思

## 内容真实性

- 不要编造用户没有提供过的设计成果、调研结论、最终方案、模型细节。
- 如果资料不足，不要补假内容，只列出缺失材料和下一步任务。
- 可以创建模板，但必须用“待补充”标注空缺内容。
