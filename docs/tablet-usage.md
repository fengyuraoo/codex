# Huawei MatePad 12 Usage

## Open

Open the deployed HTTPS link in the MatePad browser.

## Add to Home Screen

Use the browser menu and choose "Add to home screen" or "Add to desktop". The app name should show as **Speaking Map**.

## Layout

- Landscape: use **Tree**, **Detail**, and **Split** buttons to switch views.
- Portrait or narrow width: start from Tree View, tap a node to enter Detail, then use **Back to tree**.

## Protect Recordings and Data

Before clearing browser data, changing devices, or reinstalling the browser, open **Settings** and use **Export Full Backup**. The backup includes materials, recordings, review notes, and local settings.
